# Content Sources — Idiom Archives

These references support the historical notes in the Lore Vault (`src/data/lore.ts`). Each idiom is labelled in the game as **Documented**, **Partly documented** or **Origin uncertain / disputed**.

Reliability note: the notes were drafted with AI assistance and then trimmed to claims these references support. Where references disagree, the game uses hedged wording. Teachers should re-check entries before formal use, as online references can be revised.

## General references

- *Oxford English Dictionary* (OED Online) — authoritative dated citations (subscription; many HK school libraries provide access). https://www.oed.com/
- Online Etymology Dictionary (Douglas Harper). https://www.etymonline.com/
- The Phrase Finder (Gary Martin). https://www.phrases.org.uk/
- Merriam-Webster Dictionary. https://www.merriam-webster.com/
- World Wide Words (Michael Quinion). https://www.worldwidewords.org/
